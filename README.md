Sistema Bancário em Python — POO

Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio da DIO (Digital Innovation One), com o objetivo de praticar os conceitos de Programação Orientada a Objetos (POO) em Python.

O sistema bancário permite cadastrar clientes, criar contas correntes, realizar depósitos e saques e consultar o extrato bancário.

Funcionalidades

- Cadastro de clientes pessoa física.
- Criação de contas correntes.
- Depósitos com validação de valores.
- Saques com limite por operação e quantidade de saques.
- Consulta do extrato e do saldo.
- Registro das transações bancárias.

Conceitos utilizados

- Classes e objetos.
- Herança.
- Métodos e atributos.
- Classe abstrata e métodos abstratos.
- Encapsulamento.
- Listas e estruturas de repetição.
- Tratamento de exceções.

Tecnologias

- Python 3
- Git e GitHub

Como executar

1. Tenha o Python 3 instalado.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

python desafio.py

Objetivo

Praticar Python e aplicar conceitos de Programação Orientada a Objetos na construção de um sistema bancário simples.
